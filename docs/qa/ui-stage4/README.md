## 删除/迁移依据

编辑前运行 `rg -n 'icon\(|<Icon|className=|class=' src/ui src/commerce.js src/main.js src/icons.js`，并用 PostCSS 枚举全仓 `.icon`、SVG 尺寸和媒体查询。`ui/table.tsx`、`ui/entry.tsx`、`ui/primitives.tsx` 仍使用这些组件，因此没有将其当死代码删除。

删除的是指令要求清掉的重复图标宽高/描边声明，以及迁移后的原短横屏声明，组件本身与颜色、可见性等非尺寸规则保留。涉及 `.variant-card`、`.circle-score/.circle-turn`、`.build-button`、`.resource-input`、`.player-stats`、`.chat-empty/.hand-empty`、`.piece-stock`、`.brand-mark` 等。图标尺寸规则已按行内、操作、工具栏、空状态归并到同一处，兼容直接 SVG 和 React `icon-fragment` 桥接。

既有阶段 2 的测试原先要求所有反馈规则留在 `notices.css`、横屏入房规则留在 `map-first.css`；本阶段仅放宽为“基础规则仍归原文件，短横屏归入 theme”，没有删除对弹窗限宽、文字换行和反馈可见性的验证。
