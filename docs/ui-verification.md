# 联机房间界面与美术验收

## 界面行为

- 首页的在线目录仅访问当前来源的 `/api/rooms`，展示房主、人数、阶段及玩法；加载、空列表、请求失败、已满、进行中、暂停、结束分别显示。目录支持游标分页、“加载更多”及保留已加载结果的失败重试。列表中的“原身份返回”只读取当前来源本地已有的凭证；凭证不拼入 URL 或列表请求。
- 建房默认选择经典基础版和公开真人房；可改为私密。个人练习始终私密。基础版为 3–4 人，5–6 人扩充需明确选择，列表、空位、开局门槛按服务端公布的规则人数显示。
- 开局前支持显式准备/取消、房主移出玩家、转交房主、设置可见性及完整规则选项。移出/解散通知会清除当前浏览器对应的失效凭证并显示处理结果。
- “退出座位”“暂离房间”“解散房间”分别呈现。等待阶段非房主退出会提交 `leave` 并释放席位；房主需先转交才能退座，直接导航会明确保留房主身份并断开连接。对局中暂离保留身份，房主可从单独入口主动转交；解散需另行确认。
- 房间内点击品牌首页或“返回游戏大厅”先弹出说明与确认。大厅地址为已确认部署身份对应的固定白名单：阿里云 `https://magical-athlete-online.cn/`、Cloudflare `https://magical-athlete.qiuh23.workers.dev/lobby/`。不会复制邀请参数、房间码或身份令牌，也不会切换后端。
- 房间显示服务端截止时间，以服务端时间与收到快照后的经过时长计算倒计时；刷新界面不设置截止时间。到期处理由服务端裁决，收到关闭通知后立即撤下牌局与失效返回入口。
- 暂停时停止前端棋盘交互、建设与交易入口。5–6 人配对伙伴建设阶段保留银行/港口交易，隐藏其他玩家交易表单，并说明当前阶段。

## 美术与可读性

资料库作为规则与视觉研究资料，不打包其中的官方图片、扫描页、产品照或 PDF。棋盘仍是 Three.js 程序化几何；资源图标、二维棋盘、数字/港口标记及界面均为仓库代码绘制。没有将程序化几何描述为 Blender 资产。

本次新增五类原创彩色 SVG 资源插图，资源卡、等待区资源展示、二维地形与二维/三维港口共用；港口常驻文字只保留 2:1 / 3:1，中文名称保留在 title、aria-label 与悬停提示。统一资源卡色条、建设成本、二维/三维高概率红数字与概率点；为港口增加浅色底牌，发展卡增加统一的纸牌边框；二维六类地形加入原创矢量纹理以配合颜色与文字识别。三维相机按实际地块和港口标签投影边界及画布比例自动留边，大岛屿同时调整底座与二维可视范围。首页叙述压缩为短句，玩法细节留在折叠设置和玩法指南；手机上的日志与聊天默认折叠并保留未读提示、展开状态及输入草稿。桌面长房间目录单独滚动，避免挤长棋盘。手机上管理与确认操作保留足够按钮高度、页头分行、规则选项完整可读，公开房间列表不再被媒体查询隐藏。

## 可重复验证

`node --test tests/room-ui.test.js tests/connection-ui.test.js` 验证固定大厅白名单、目录状态、服务端时间倒计时、退出文案与身份失效后停止重连。

`node scripts/room-experience-browser.js` 连接默认 Node `http://127.0.0.1:5175`；可用 `TEST_URL=http://127.0.0.1:8788`、`TEST_LABEL=worker` 复用到本地 Worker。脚本覆盖目录失败/重试/空/已满/分页、公开/私密/练习、4/6 位真人准备与完整初始放置、6 人配对回合界面、移出/转交/退座重新加入、两个小变体、隐藏信息、暂停截止时间与身份恢复、确认解散，以及桌面/手机布局。截图保存在忽略的 `test-results/`。

`node scripts/integration-browser.js` 使用本地部署元数据模拟两种生产入口；大厅目的页面由浏览器拦截在本地，不访问或修改生产。验证跨服邀请拒绝、原服务器邀请码、返回确认/取消和不带参数的大厅目的地址。

`npm run test:browser` 与 `npm run test:multiplayer` 保留基础版练习、3D 射线落子、二维后备棋盘、聊天与刷新恢复回归。浏览器仿真不能证明实体设备 Safari、系统键盘或真实移动网络的表现。

实际执行结果由本次 PR 的验证记录列明。
