# 公开行动反馈与地图定位

基于 `9be4453`（2026-11-06 拉取的 main），参考胡闹运动会的已确认事件游标与手动中断方式。

## 玩家可见行为

- 道路、村庄、城市、强盗移动与抽牌显示行动者和简短说明；可定位的行动在 3D 和 2D 棋盘上显示青绿色与白色静态轮廓。
- 一次掷骰的实际资源生产只有一条摘要，同时标记所有产出地块。被强盗阻断、无人收获或银行未发放的地块不标记；不显示对手资源种类、数量或手牌。
- 180 毫秒内到达的事件统一处理；相邻 2.2 秒内的公开行动合并成一条提示，重复文案显示次数。原事件顺序与所有位置保留，提示最多展示两组说明及其余行动数量。高亮 9 秒后移除，提示可收起或再次点击「定位」。
- 「全局」返回整个岛屿并暂停跟随；「跟随中／已暂停／跟随关」可显式暂停或恢复。设置中可永久关闭自动跟随，并选择减少动态效果。偏好保存在本浏览器。
- 自动定位保留观察方向，按当前未被顶栏、提示、手牌与底部操作栏占据的矩形计算位置，平滑平移并限制缩放和俯仰。两次自动定位至少间隔 3.5 秒，期间新事件仍显示静态标记，不积压镜头。
- 点击落子会立即停止正在移动的镜头；拖动、双指操作、滚轮和键盘缩放会暂停后续跟随，直到玩家主动恢复。普通落子点击不会永久关闭跟随。
- 选择落点、提交行动、输入、弹窗操作、暂停对局与后台页面均不自动定位。事件到达时或等待展示期间被这些操作打断，就只展示提示和静态标记；操作结束后不会补播镜头。选择落点时「定位」禁用。
- 默认遵循系统减少动态效果设置；开启后没有自动镜头和惯性，玩家点击「定位」时直接显示位置。手动视角在屏幕旋转和 HUD 尺寸变化时保留，必要时可主动回到全局。

## 权限、恢复与规则

`shared/game.js` 在规则行动确认后追加公开 `presentation` 流。每局有独立 epoch，事件使用单调递增 ID，最多保留 80 条。字段只包含种类、行动者、公开文字和地图坐标；个人视图显式投影这些字段，不复制原始命令、隐藏手牌、发展卡对象、牌堆或交易资源包。

发展卡购买只提示「购买了一张发展卡」，已公开打出的发展卡可显示卡名；交易和弃牌只提示公开结果。建造、移动强盗和资源生产仍由原服务端规则裁决。展示计时器不发送规则行动、不阻塞按钮、不改变回合顺序。

首次进入、刷新、重连、换房、重新开局和缺失历史区间只建立当前事件基线。重复快照、旧快照和已确认命令重试不会重播；旧存档仍兼容，在新事件流建立时初始化基线。
