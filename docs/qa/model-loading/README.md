# Catan 模型渐进加载（2026-11-12）

首屏改动最初基于 main `ee2db34`，随后兼容已合入的道路版本 `7ec8c3c`。本改动调整模型请求、显示时机、缓存、静态资源响应和失败恢复，不修改道路造型/灯光代码、游戏规则或已认可的 GLB，也不部署。

## 改动

- 同一棋盘最多 4 个并行模型加载/解码任务，先请求覆盖当前地块最多的地形；建筑只加载当前实际使用的变体，强盗不存在时不请求强盗。首页演示只准备其会展示的那一座村庄与城市，不下载另两款建筑。
- 地形不再等所有地形、建筑和强盗 `Promise.allSettled` 后整板替换。加载中只保留低矮资源色底板；每个地形资产就绪后局部淡入 240ms，岸线、数字、其他已加载地块、相机与合法落点不重建。减少动效/暂停直接完成过渡。
- 失败的地形或港口启用现有程序化回退，提供明确的重试按钮。不自动循环重试；网络请求 30 秒超时。过期地图和已销毁棋盘的回调不会重画新场景，切换地图取消尚未开始的无关请求。
- 同页 2D/3D 切换复用原始 GLB 字节：24 MiB LRU 上限、5 分钟闲置过期。每个 Board 仍独立解析并拥有 Three.js 资源，避免一个棋盘销毁另一个棋盘的网格。失败和解析错误不留坏缓存。
- 页面内存缓存之外，新增浏览器 HTTP 磁盘缓存：构建为每个 GLB 生成内容 SHA-256 URL，未变模型跨构建/站点版本保持相同路径，变更模型自动换路径。详情见 [缓存验证记录](../../visuals/asset-caching.md)。不使用 Service Worker 或全量预下载，不压缩或降低模型质量，首次访问仍需传输当前地形。

## 静态请求集合计算

使用仓库真实文件大小与既有首页/4人/6人测试夹具计算，不是网络速度跑分：

| 场景 | 原请求数 / 原字节数 | 新请求数 / 新字节数 |
|---|---:|---:|
| 首页 | 17 / 11,370,756 | 14 / 9,859,124 |
| 4 人对局夹具 | 18 / 11,354,508 | 16 / 10,166,308 |
| 6 人对局夹具 | 21 / 14,871,488 | 19 / 13,683,288 |

首页少请求 1,511,632 字节（约 13.3%），不再让隐藏建筑阻挡任何已完成地形显示。实际压缩传输字节、缓存命中和加载秒数取决于服务器与网络，未作结论。

## 验证

首屏独立改动全量单测 **213/213** 通过；缓存扩展、道路兼容后的结果见缓存验证记录。`npm run check`（含 TypeScript）、`npm run build`、`npm run worker:check` dry-run 和 `git diff --check` 通过。生产构建仍有既有 Three.js 大分包提示，未为消除提示调整阈值。

- `tests/model-loading.test.js` 覆盖可见资产集合、4 槽并发、逐个回调、请求去重、显式重试、有界缓存/过期/失败清理、超时、局部 mesh 身份不变、渐入材质释放、地形失败回退、迟到销毁、切图撤销队列和过期回调隔离。
- 原资产真实 GLB 哈希、几何、OwnerTint、暖窗与强盗测试保留。因不再默认加载未显示模型，相关测试显式请求它们要检查的建筑或强盗，没有降低素材断言。
- `scripts/model-loading-browser.mjs` 提供慢请求阻塞、部分先显示、其他地块与数字身份保留、2D/3D 缓存复用、失败后仅重试一个资源、19/30 地块和手机横竖屏验收脚本。

当前执行环境的 Chromium 无法建立所需 Unix socket（`Operation not permitted`）；经权限升级重试仍失败。云浏览器也不能访问该执行工作区的本地预览端口。因此**浏览器脚本未完成、没有生成通过验收的截图**，不声称已目检淡入、手机布局或实测帧率。发布前需要在可运行浏览器的工作区执行该脚本并查看截图。

复现：

```sh
npm test
npm run check
npm run build
XDG_CONFIG_HOME=/tmp/catan-loading-config npm run worker:check
npm run dev
# 另一个终端；可通过 BROWSER_EXECUTABLE 指向已安装 Chromium
TEST_URL=http://127.0.0.1:5175 node scripts/model-loading-browser.mjs
TEST_URL=http://127.0.0.1:5175 BROWSER_EXECUTABLE=/usr/bin/chromium node scripts/visual-assets-browser.mjs
```

不应把新增浏览器脚本当作已运行通过的结果。手机浏览器模拟即使通过，也不等于实体 iPhone/Android 网络、发热或续航验证。
