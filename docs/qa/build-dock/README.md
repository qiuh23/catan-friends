基线：`fe8810decf006f2af7e7a12e08a8c0a8d4ba6f7b`（2026-11-13 main）。本记录描述合并前的本地验证；提交、合并和发布状态以对应 PR 与 CI 为准。

## 行为

- 点道路、村庄或城市仍立即进入合法位置选择。费用显示在原底部操作栏内，使用资源图标和数量，不再向棋盘或手牌上方浮出。
- 缺资源显示缺口与感叹号；非自己回合显示等待提示。两者都不进入选址。免费放置显示“本次免费”，发展卡保留明确购买按钮。
- 点地图非交互空白处或界面其他非交互空白处只收起费用，保留选址。收起后已选建造按钮显示“取消道路／村庄／城市”，可以明确退出。
- 拖动、双指缩放、取消的指针事件及相邻落点歧义不会收起费用。合法落点仍走原服务端提交，费用取消入口不提交游戏动作。
- 成功、回合／阶段改变、退出房间清理相应状态；当前资源或合法位置失效时停止普通选址。
