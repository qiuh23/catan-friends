# 本地验证记录

2026-11-05，Windows / Node.js 24.11.1。

## 已验证

- `npm test`：18 项通过。覆盖 60 张随机地图拓扑与 6/8 分布、3/4 人蛇形开局、交易/建造非法操作、资源生产与守恒、七点/强盗、港口比例、发展卡、最长道路被截断、最大军队平手、隐藏胜利点、版本与去重、电脑接受交易。
- 规则测试包含 5 个随机种子的完整电脑对局，均达到胜利终局，每一步验证每类资源总量为 19。
- Node 真实 WebSocket 测试：三人同步、越权失败、隐藏手牌、动作去重、重连保留身份、陌生房间拒绝、开局后陌生身份拒绝、服务重启后恢复棋盘与回合。
- `npm run test:browser`：1440×960 桌面与 390×844 手机；练习开局、两轮初始建造、掷骰、刷新、规则弹窗、二维/三维切换；没有页面脚本错误或横向溢出。
- `npm run test:multiplayer`：三个独立浏览器上下文走真实界面建房/加入/准备；投影合法交点并点击 3D 棋盘完成落子，随后完整初始布置、聊天广播、刷新恢复与隐藏牌隔离。
- `npm run test:worker`：Cloudflare 本地模拟实际建房/加入/准备/开局、个性化快照、alarm 电脑行动、原身份恢复。
- `npm run build`：Vite 生产构建通过。
- `npm run worker:check`：Worker dry-run 打包通过，绑定与迁移可解析。
- 初次依赖安装审计：0 个已知漏洞。
