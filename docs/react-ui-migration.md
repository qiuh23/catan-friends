# React + TypeScript 界面迁移

2026-11-11。基于卡坦岛远端 main `61d13cd` 和此前确认的地图优先视觉结果，迁移正式 `index.html → src/main.js` 入口的首页、候场、对局及结算。参考巫师牌已落地的 React 界面（main `6f3733e`），没有新增独立样板入口。

## 责任边界

| 责任 | 实现 | 约束 |
| --- | --- | --- |
| 地图拓扑、规则、随机与个人视图 | 原 `shared/board.js`、`shared/game.js`、`shared/random.js` | Node 与 Cloudflare 共用；React 不裁决规则、不生成随机结果 |
| 房间权威、存档与联机 | 原 `shared/room.js`、`server/`、`worker/`、`src/connection.js` | 保留身份认证、版本、请求 ID、去重、权限投影、暂停、期限与重连协议 |
| 客户端协调与展示草稿 | `src/main.js` | 继续处理命令、会话、浮窗、焦点、输入、场景和反馈生命周期；通过原 Connection 提交动作 |
| 界面模型与稳定根 | `src/ui/types.ts`、`src/ui/root.tsx` | React 19、严格 TypeScript、`useSyncExternalStore`；只接收当前玩家已过滤的快照及展示状态 |
| 首页、候场、玩家与结算 | `src/ui/entry.tsx` | 保留建房、加入、原身份返回、人数匹配、准备、房主权限及完整最终排名 |
| 对局与浮窗内容 | `src/ui/table.tsx` | 保留资源、费用、骰子、公开分、合法位置、发展卡、强盗和必选决策 |
| 交易及纯展示计算 | `src/ui/commerce.tsx`、`src/commerce.js` | JSX 生成交易界面；纯函数计算可支付、限制和归一化草稿，成交仍由服务端校验 |
| 图标、资源美术与主题 | `src/ui/primitives.tsx`、`src/ui/theme.css` | 静态 SVG 词库桥接仅用于既有图标与资源插画；玩家文字由 React 转义 |
| 三维／二维地图与镜头 | 原 `src/board.js` 及场景模块 | Three.js、真实地形与程序化建筑、道路、港口、拾取和镜头继续独立维护 |

主界面内容由 JSX 生成，不把整页 HTML 字符串包进 React。根只创建一次，不按服务器版本或页面状态更换 `key`；React 保留 `#board` 这个空场景挂载点，Board 持有其中的 canvas／SVG。报价、聊天、公共快照和普通浮窗更新不会重建 WebGL 场景。同步提交让原控制器在 React 更新后读取正确的 DOM 尺寸，再更新镜头、反馈及浮窗位置。

`UIModel.state` 是 `viewFor`／房间服务已经过滤的个人视图。当前玩家的资源和发展卡可以显示，其他玩家仅有公开张数及规则允许的公开分。React 不接收权威 game、牌堆顺序、随机流、身份映射或恢复凭据；`last` 只传房间 `code`。原身份凭据继续由控制器和 Connection 管理，恢复入口只发起既有恢复动作。

## 界面、草稿与镜头

主题采用与巫师牌相同的 `--ui-*` 语义词汇，统一系统字体、4px 间距基准、数字对齐、44px 触控目标、焦点轮廓、按钮状态及浮窗圆角／阴影。卡坦岛保留海水青绿、暖白、森林与土地的配色，以及既有海岛与资源插画。[Astryx](https://github.com/meta/astryx) 用作主题分层参考，本次未引入其组件或新增样式运行时。巫师牌海外聊天工具按钮的样式修复在其自身仓库完成。

地图保持全屏主舞台，玩家、资源及建造／回合操作为紧凑浮控。关键费用、资源数量、骰子、分数及合法位置留在行动附近；规则、记录、玩家详情与设置收进菜单。交易只在必要层级显示“你付出／你获得”，保留每项资源数量、比例、库存及完整方向信息。结算首先展示结果和再开／返回按钮，完整公开成绩在同一浮窗内滚动查看。候场设置和结算提供本站游戏大厅入口，离站沿用暂离确认，返回首页及原身份恢复入口继续保留。

普通浮窗可点击背景关闭；强制弃牌等必选决策阻止背景误关。草稿按本站、房间与当前身份保存在既有会话存储中，切换交易方式、关闭／重开、快照更新及刷新继续恢复。海外聊天在等待 ACK 时仍可编辑；收到确认只清除已提交且未再编辑的文本，保留新草稿、焦点和选择范围。必选数量及发展卡选择沿用原控制器，不由组件挂载触发游戏动作。

竖屏根据可用地图区域调整取景，3／6 人岛屿分别计算投影；320px 窄屏补充放大。手动旋转、缩放或切换渲染器后，镜头保持原手动视图；修正已有手动投影被后续 HUD 测量覆盖的问题。自动跟随、复位、二维键盘交互和减弱动态效果保留。实际覆盖与设备限制见 [验收记录](qa/react-migration/README.md)。

## 国内／海外与发布

通用 React、主题、布局、交易与镜头优化同时应用于两版。国内继续使用原建筑／艺术固定昵称及稳定 ID，首页可换名、进房固定，不提供聊天、快捷短句、表情或改名；国内说明不出现“聊天仍可用”。海外继续支持自定义昵称、聊天、历史与输入恢复。此次不改变国内昵称或交流方案，也不混用两站房间、邀请码、凭据、存档和返回大厅目的地。

保留原 Vite、Node、Wrangler 和双站构建入口。`npm run check` 执行协调器语法与 UI 严格类型检查，构建脚本在生成产物前运行 TypeScript 检查。手动正式入口回归使用 `scripts/react-migration-browser.mjs`；完整截图矩阵没有加入默认远端发布流程。

卡坦岛继续由现有 main Checks 产物经受检查的阿里云／Cloudflare 发布链交付；不新增 Cloudflare Native Builds、命名空间或第二个发布者，不修改生产授权变量、Secret、主机配置或存档结构。巫师牌继续沿用自己的 main 自动部署配置。现有门禁、精确提交校验、备份与兼容回滚要求仍以 [自动部署说明](automatic-deployment.md) 和 [运行迁移说明](random-chat-report-operations.md) 为准。

本轮源码和本地验证不代表已经合并、实际发布或通过公网验收。最终检查结果及明确未覆盖项集中记录在 [迁移验收](qa/react-migration/README.md)。
