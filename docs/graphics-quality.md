# 玩家选择 3D 画质

- 首次进入默认高画质。首页的“画质设置”和对局设置均可随时选择“高画质 / 省电”，保存在当前站点、当前浏览器的 localStorage。
- 高画质保留实时阴影、完整天空和港口点光。触屏、窄屏、低内存不再改变这些视觉内容。尺寸仍控制触控布局、像素预算及首页/日夜计时器的合理刷新节流；二维回退、模型加载失败回退不变。
- 省电仅由明确选择触发，复用场景与相机，不重建棋盘或改变游戏状态。
- 可选提醒只统计真实主动动画，包括首页展示、持续拖动及连续相机/反馈动画。普通静止日夜 tick 不算主动动画。以原计划帧间隔为基准，20Hz 本身不算卡顿。
- 连续三个 2 秒窗口中，至少 70% 帧间隔超过 max(80ms, 两倍目标帧间隔)，每窗口至少 10 帧，才尝试提醒。初始化、模型铺设、前台失焦/后台、不可见、对话框、暂停与 resize 均排除，并有 2.5 秒稳定期。超过 500ms 的间断重置采样。
- 提醒不抢焦点、不弹模态框，在 HUD 下方为其保留地图空间；必选任务或可用高度不足时不显示。15 秒忽略后消失，保持高画质；“保持”和关闭均不降档。
- 提醒实际显示时写入持久已提示标记。刷新、重连和下一局不会重复。明确选过任意画质后也不再提醒。存储不可用时仅在当前页面记忆。

## 验证

针对性单元检查覆盖偏好持久化、存储失败、一次提醒、20/24/30/60Hz 正常节流、持续卡顿、瞬时卡顿、后台/加载/暂停间断，以及 Three.js 场景的高/低档阴影、天空和港口灯切换。浏览器环境没有 WebGL，DOM/二维回退布局与交互和真正 GPU 视觉/性能验收须分别记录。
