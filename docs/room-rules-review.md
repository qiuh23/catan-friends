## 房间行为

沿用既有 `Room`、Node WebSocket/JSON 存档和 Worker SQLite Durable Object，不重写整套游戏后端。两端共用 `shared/room.js` 的权限、身份、期限、关闭、个性化视图和 AI 控制。

- 创建时选择公开/私密与规则；公开真人房列表仅有房间码、房主昵称、状态、人数、容量、公开规则及保留截止，不含身份令牌/摘要、玩家 ID 清单、资源、发展牌、牌堆或聊天。每页最多 40 项，支持游标分页；Worker 对目录候选再向拥有该房间的 DO 核实，私密/练习/已关闭房不会公开。目录故障显示连接失败，不能伪装空列表。
- 基础默认 3–4 人，选择 2025 第六版人数扩充才开放 5–6 人，房主修改规则后真人重新准备。服务端校验容量、规则支持范围、在线和准备，不只依赖按钮禁用。
- 等待中非房主主动退出座位，席位立即释放，旧身份摘要撤销；踢人限开局前，由房主执行，通知被移出者并撤销所有旧连接。原浏览器下次重新入座使用新凭证。网络断线保留等待座位和身份。
- 房内可主动转交给另一位真人，立即转移设置/开局/暂停/解散权限；不重新排序座位，不改变已有回合。原房主保留普通玩家座位。等待房主直接退座被拒绝，须先转交或单独确认解散；房主仍可从界面暂离并保留恢复能力。
- 对局中暂离保留身份/手牌/座位；没有资源处置投票、续赛投票或掉线自动代打。AI 保持原独立策略，全部真人离线停止；其他真人在线时可继续电脑回合，但不能续房主期限。
- 解散由房主独立确认，服务端验权，所有有效连接收到关闭通知。关闭后删除对局、身份映射、手牌、发展卡、操作回执及聊天，只保存小型永久关闭记录；房间码不重复使用，旧链接/令牌/重启不能复活。

| 场景 | 服务端期限与结果 |
|---|---|
| 普通真人房 | 房主最后一个有效连接离线后 30 分钟；期限内回来恢复身份并清除普通离线截止 |
| 房主主动暂停的真人房 | 本次暂停第一次离线起固定最多四小时；重连、再次离线、转交、其他人聊天都不延后，仍暂停时到点直接关闭；正式恢复后清除此暂停周期 |
| 个人练习 | 原身份离线后十分钟，暂停不扩大时间，拒绝其他身份加入且不公开 |
| 房主一直在线 | 不依据普通闲置或最后游戏操作关房；旧 48 小时活动清理不再控制生命周期 |
| 到期 | 在线玩家看服务器绝对截止与倒计时；到点先关闭/持久化，再拒绝加入和旧动作，清理私密数据并通知成员 |

卡坦岛的固定四小时上限包含本次暂停已经开始后的短暂返回。巫师牌保留它现有的“房主在线不因闲置关闭；再次离线沿用本次暂停原截止”和到期续赛投票语义，不为了统一 UI 改动其玩法。

## Node、Worker 与故障恢复

Node 在每次确认前原子替换 JSON，每房串行；首次建房用独占写入分配房间码，避免并发覆盖。启动扫描全部存档，恢复/清理到期房；期限独立 timer + 三十秒复核 + 读写入口检查，普通聊天/AI/刷新不续期。所有同身份连接被新页面接管，关闭旧连接不能把仍有效的新连接误算为离线。关闭、踢人和退出后的请求先检查成员权限，再查成功回执。

Worker 保留现有 `ROOMS` 绑定、`CatanRoom` SQLite class 及 v1 migration；在同一 namespace 的保留内部对象中保存公开目录，不增加外部数据库、KV、绑定或迁移。每房请求/alarm/关闭串行，状态与下一 alarm 使用 SQLite 事务保存；持久化失败撤销内存状态，不确认未保存动作，alarm 重试不多走一手 AI。目录写失败不撤销已经提交的游戏命令，重试目录；列表永远从房间权威重新确认公开性和期限。

Worker 从序列化 socket 身份和运行时 auto-response 时间恢复连接，九十秒无有效应用心跳视为失效；Node 使用既有协议 ping/pong 检测。有效浏览器每二十秒发应用心跳。半开连接检测存在网络/运行时延迟；保留时间从服务器判定失去最后一个有效连接起算，不能声称精确知道物理断网瞬间。读目录、sync、alarm 都会重建有效连接状态，避免延迟 alarm 时目录读取误取消唯一清理 alarm。临界点先检查旧截止再承认返回，刚过期的消息不能清除截止复活房间。

冷重启失去的连接以最后持久化的 `hostSeenAt` 作为保守观察基准，停机时间计入原期限；已保存的普通/暂停截止原样保留。进程崩溃的真实断网时间无法事后重建，该基准通常比真实离线稍早；正常在线以三十秒检查点更新。Worker 正常休眠且 socket 存活时不误作断线。永久关闭记录用于防止老房间名复用，属于刻意保留的少量数据，不宣称已删除一切字节。私密清理指当前在线存档，不擅自改动原有受保护备份的保留策略。

## 存档兼容性

房间包由 v1 增量升级 v2，保持旧游戏、身份摘要、座位、资源、牌堆和回执。旧存档缺少规则选项时仍为基础版；缺少公开性时默认私密，避免历史房间被新目录公开；缺少独立 hostId 时采用原首座位。旧存档没有可靠离线/暂停历史，只能用原 updatedAt 作为保守观察基准；早已超出新保留期的历史房间会关闭，不能承诺从未知连接历史无损恢复所有旧闲置房。Worker 旧版未标记 practice 的历史房也无法事后可靠识别，默认按私密真人房处理，不能捏造练习十分钟历史。

新五/六人局和配对回合不能交给原 main 的规则引擎继续运行。升级可读取旧局，不代表旧代码能正确读取/续玩所有新局。保留期内身份恢复、最少/最多人数和配对阶段的磁盘/DO恢复均测试。存档目录和资料原件不进 Git。
